# ADR 035 — Named, compiler-versioned source standard library

## Context

Round 13 makes source HOFs possible across modules, but module qualification costs
8 tokens versus 4 for a same-named intrinsic. Source-only algorithms must meet
both observable semantics and measured speed; proof visibility alone is insufficient.
This ADR supersedes ADR 026's placement policy, retaining its requirement that
proofs come from bodies rather than annotations.

## Decision

Reserve `!name(...)` for core and compiler-shipped std names. Existing meanings
remain: zero-argument `!map()` constructs a map; two-argument `!map(&f,sequence)`
selects a std algorithm. No other arity changes an old operation's meaning.
Unknown names remain errors; external modules cannot shadow these names. Future
std names require a specified reservation and compatibility audit.

Ship pure NIL algorithms under `std/`, embedded with the compiler and snapshotted
from those exact sources. Version std with the compiler, not independently; no
search path, environment override, flag, manifest or import in programs. Parse,
relocate and specialize through the existing frontend/module machinery; root
records remain nominal. Load only referenced algorithms, so unrelated programs
retain old IR. No special purity/ownership trust: ordinary validated HIR and
existing body-derived summaries govern arena/quota/roots/effects/reuse.

Introduce `!ID.EXPORT(args)` as a numeric qualification alias for existing loaded
module/plugin exports, using the same visibility and collision rules. Callback
references may use `&!ID.EXPORT`. No automatic third-party loading. Canonical
integer IDs avoid arbitrary alias-binding design this round.

Measured tiktoken 0.12.0 (cl100k and o200k identical):

| Spelling | Tokens |
|---|---:|
| `!sort(a)` | 4 |
| `!find(a,10,b)` | 7 |
| `!map(&c,a)` / `!filter(&c,a)` | 6 / 6 |
| `!fold(&c,a,0)` | 8 |
| local `b(&c,a)` | 5 |
| `!plugin(7,0,a)` / `!7.0(a)` | 8 / 6 |
| `!plugin(7,12,a,b)` / `!7.12(a,b)` | 9 / 7 |
| `!7:0(a)` / `!7/0(a)` | 6 / 6 |
| hypothetical `!m.a(a)` | 5 |

Choose numeric dot: meets the two-token gate without a new manifest naming layer.
Named std has zero import/manifest tokens. No identifier/punctuation shortening.

### Placement rule and all 35 intrinsics

Move an algorithm to source std only if same-named calls cost the same tokens,
all semantics/diagnostics/order are preserved, and O2 speed reaches core parity.
Otherwise retain it with the measured or demonstrated blocker. Types, elementary
storage/element access, scalar/bit primitives and host authority stay core.

| Intrinsics | Placement and reason |
|---|---|
| buffer, bytes, map, bytemap | Stay: typed storage constructors |
| get, key, size | Stay: element/metadata access and owned projection |
| i64, u64, u128, f64, trunci64, truncu64, bits, floatbits | Stay: scalar representation/conversion primitives |
| read, write, out, env, random, directory | Stay: host authority/effect contracts |
| concat, slice, insert, put | Later: callee ownership/reuse prerequisite, draft ADR 036 |
| sort | Later: callee-update reuse plus appropriate library algorithm |
| equal | Already outward; harden generic structural lowering, retain compatibility enum |
| find, has, parse | Attempt now; retain if source cannot preserve checks/quota or speed |
| parsebuf, format, parseu64, parseu128, parsef64 | Later: checked failure/owned numeric-text contract and measurement |

Enum variants remain 35. Report executable core implementations separately: starts
34 because equal already executes provider source. No new intrinsic for algorithms.

### Algorithms and forecasts

Map/filter support Bytes and i64 Buffer. Callbacks receive i64; map returns i64
(byte results retain E014 checks), filter returns bool. Fold receives i64 accumulator
then i64 element and returns i64; initial value explicit. Traversal is ascending
index, once per original element, selected effects/traps in order; immutable input
and original aliases remain observable. Map allocates an exact-length output,
filter grows an owned output with existing geometric concat, fold allocates none.
All capacity charges and E013 remain visible. Empty input invokes no callback.
Callback bodies determine all summaries. Dynamic dispatch/captures remain excluded.

Forecast map/filter/fold versus the identical caller loop: O2 ratio 1.00–1.10,
including external-module copies of the control. No claim versus vectorized C++
filter, and no callee-update proof change. B3 bodies use direct loop-local updates,
not per-element allocating helper returns. Named call token targets above are exact.

Find: source scan forecast parity only with a whole-body, identity-independent
recognizer preserving start E012 before byte E014, including all dead instructions.
Source primitives cannot directly raise arbitrary errors; constructing zero bytes
for an E014 check can change quota behavior. Has: source key traversal allocates
where core hashing borrows; expect failed quota/speed equivalence unless a valid
smaller contract already exists. Parse: scalar decimal scan is expressible, but
E016 failure and overflow checks cannot silently become E009/E022. Attempt source
candidates and report these blockers; never label a wrapper around core a migration.
No new checked-trap primitive is authorized by this ADR. Conditional retention is
an intended outcome, not permission to weaken semantics.

Normalize only proved commutative equality/Add nodes in recognizers. Preserve
ordered/trapping instructions and bounds; tests must cover mirrored shapes and
negative near-matches/dead reads. Do not grant an opaque semantic annotation.

## Alternatives

Opaque/native std calls lose body proofs. Filesystem std discovery makes binaries
non-self-contained and changes snapshots. Named module aliases need another
binding/manifest mechanism; numeric qualification is smaller and sufficient.
Keeping all algorithms as opcodes does not implement the maintainer's placement
rule. Inventing unchecked failure/ownership shortcuts to force migrations is rejected.

## Consequences

Std source is inspectable, compiler-versioned and independently validated. Numeric
module naming saves two tokens but retains explicit manifests for third parties.
Some migrations may remain blocked by primitive contracts rather than speed.
Existing corpus sources/oracles/goldens/baselines remain untouched; counts unchanged.

## Status

Accepted preregistration before implementation. Measurements and retention verdicts
will be recorded separately. No push authorized.
