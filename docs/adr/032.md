# ADR 032 — General modules through the source provider loader

## Context

ADR 029 already resolves local manifests, snapshots typed source, checks exports,
and links validated code. ADR 026 requires proof-visible boundaries. Building a
second loader would duplicate these checks. General application modules need
allocation, effects, local recursion and transitive dependencies.

Before implementation, `benchmarks/module-study/naming.py` measured hypothetical
qualification of all local calls in the unchanged 66 verified corpus sources,
using the pinned Gemma/Qwen vocabularies and cl100k/o200k (no inference):

| Cut | Calls | Gemma extra | Qwen extra | cl100k extra | o200k extra |
|---|---:|---:|---:|---:|---:|
| Original 24 | 30 | 122 | 151 | 151 | 150 |
| External 42 | 298 | 1296 | 1515 | 1483 | 1497 |
| Combined 66 | 328 | 1418 | 1666 | 1634 | 1647 |

These are whole-source token differences, not isolated spelling estimates or
verified program rewrites. All-call qualification costs 11.2–17.3% combined;
therefore local positional calls must remain local. Actual split examples will
measure sharing and manifest overhead separately. Density is not model efficiency.

## Decision

Extend the **same manifest reader, bounded source reader, export resolver and
syntax linker** with `nil-module 1`. Existing `nil-plugin 1` contracts and calls
remain unchanged. No new grammar or intrinsic is needed: the existing
`!plugin(ID,EXPORT,args...)` is a compile-time export reference for either kind.
Module references resolve to ordinary HIR `Call`, with all module functions linked
before type validation. Local positional labels are relocated deterministically;
only explicit exports cross files. Imported labels are not CLI entry labels.
The root file retains function 0 as default entry and existing explicit entry IDs.

A module declares `id`, `source`, one or more `export OP LOCAL_LABEL`, and optional
`import RELATIVE_MANIFEST` lines. Paths are relative without parent traversal;
canonical-path caching handles shared dependencies and detects import cycles.
Distinct paths claiming the same global ID fail E024. Direct imports alone are
visible in a module; transitive dependencies do not silently re-export names.
Root visibility is the explicitly passed manifests. Shared modules load once.
Manifest ID zero remains reserved. Graph size/depth and aggregate source/function
counts are bounded, including unreferenced imported source.

Allocation and host effects are permitted in modules, including allocation-return
calls. They use the caller's arena, live-capacity quota and ordinary root tracking;
existing whole-program borrowing summaries prove safe nonallocating cases and
retain conservative transfers otherwise. No declarations grant purity or reuse.
Recursion within a module is ordinary recursion with ordinary caller fuel/depth.
Calls across an acyclic import graph are allowed; cross-module mutual recursion
would require an import cycle and is rejected. Transitive imports are supported.
Borrow plugins retain their independently verified no-allocation/no-host/no-nested-
provider/no-recursion policy and atomic caller accounting.

Nominal types remain declared in the root registry, injected into module source
exactly as into providers. Modules may use but not add/redefine records in v1;
this restriction avoids divergent layouts and can be relaxed separately. All
existing types are available to modules without plugin borrow capabilities.
No native/foreign loading, addresses, sandbox claim, packages or remote fetching.

Manifest/version/path/export/visibility/cycle/limit failures use E024. Arguments
still evaluate left-to-right, selected lazy arms alone execute, and ordinary
callee traps/effects follow arguments. Signature mismatches remain E006/E007;
body/type errors retain their existing codes. Structural duplicate local labels
remain E003. Link snapshots survive later source changes.

ADR 026 classification: manifest import/export and ordinary call relocation are
**core linking/type identity**, not library algorithms. No convenience operations,
types, intrinsics or source punctuation are added: intrinsic delta **0 (32→32)**.

## Alternatives

A separate named-module parser and HIR operation adds a second proof boundary and
single-file overhead without evidence. New qualified spelling could be shorter,
but requires a syntax experiment; this prototype measures the existing primitive
first. Opaque native libraries lose proofs and need a different trust/lifetime ABI.
Import cycles and per-module nominal registries are deferred rather than weakening
validation. No attempt to solve grep's runtime multi-file fixture adapter is implied.

## Consequences

Multi-file programs gain normal allocation/effect semantics and compiler-visible
calls. Explicit imported references and manifests cost tokens; shared source can
amortize that cost but small splits may be larger. Single-file source and lowering
are unchanged. Allocating imports remain conservative, exactly like local calls.

## Status

Accepted for this prototype before implementation; validation and measured split
costs will be reported separately. No push authorized.
