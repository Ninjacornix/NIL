# ADR-007: Plugin semantic boundary

## Context

The brief and report agree that plugins should be typed instruction sets and cannot add arbitrary parser syntax.

## Decision

Reserve a conceptual generic plugin call with plugin/op identity and operands. Plan registry signatures, debug names, effects/capabilities, lowering and runtime requirements. Implement nothing until M8; use one nil-test plugin first.

## Alternatives

Custom parser extensions; conventional textual libraries alone; global numeric registry; full dynamic ABI now.

## Consequences

Stable IDs plus local dense aliases are candidates. Manifest serialization, ownership, versioning, C ABI, trust and sandbox rules remain open; no published ABI exists.

## Status

Accepted fixed-grammar constraint; ABI proposed.
