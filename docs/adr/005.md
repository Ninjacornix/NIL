# ADR-005: Type system and integer semantics

## Context

Research alternates i32/i64 and broad type sets; the current brief explicitly limits M1 to integers and functions. Overflow and memory policy are unspecified.

## Decision

Propose only signed i64, explicit function boundary types and deterministic local propagation from operation signatures. No implicit conversions or general inference. Checked add/sub/mul and signed division trap on overflow, zero divisor and MIN/-1.

## Alternatives

i32, arbitrary precision, wrapping arithmetic, undefined overflow, broad inference.

## Consequences

Trapping semantics prioritize visible mistakes in generated programs and equal debug/release behavior. This policy is reversible before format stabilization; future backends must preserve it or explicitly revise the specification.

## Status

Proposed M1 policy.
