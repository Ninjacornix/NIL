# ADR-010: Measurement and scope gates

## Context

Research uses TTC/TTCP; the brief asks for aggregate TCR and warns against confusing bytes, tokens and correctness. The latest user instruction requests setup and concrete plans.

## Decision

Use failure-inclusive aggregate TCR plus per-trial TTCP-out/total and Solve@budget, with source-token count separate. Record actual provenance, identical oracles and frozen vocabulary tracks. Finish setup/plans only; mark M1 unimplemented.

## Alternatives

Success-only token averages; character-count proxy; silently executing the full initial implementation request after scope was narrowed.

## Consequences

No NIL efficiency claim exists yet. Models, budgets, sample sizes and acceptable correctness/performance margins must be selected before paid or publishable experiments.

## Status

Accepted methodology; experiment thresholds open.
