# ADR 019 — Rootless scalar lazy regions

## Context

The 16 MiB newline scan measured 161.873 ms; an equivalent loop without a lazy
conditional is approximately 10 ms. Root retention rejected all nested regions,
forcing sequence roots/live charges to transfer at every iteration even when
conditional arms only yielded scalar constants. Laziness, traps, effects and
capacity-aware E013 semantics must remain unchanged.

## Decision

Add a recursive HIR proof for nonallocating scalar instructions/regions. Allow
constants, arithmetic, comparisons, length, index and nested qualifying Ifs.
Require every result to be i64/bool. Sequence captures remain semantically live
through the branch according to existing capture-union liveness. Qualifying lazy arms
borrow inputs without redundant physical root slots; they cannot collect,
reallocate, return sequences or otherwise observe omitted root registrations.

Apply borrowing at lazy edges and conditions covered by the full loop retention
proof. Preserve original condition/finish transfers in unproved allocating loops:
broader placement changed append lowering and measured an 8–9% slowdown. The
final placement preserves append/transform IR exactly; the scalar proof remains
general and unchanged. This is an explicit performance-driven placement decision,
not a hidden narrowing to avoid a failing correctness case.

Loop root retention accepts these nested scalar regions alongside its existing
identity/straight-last-use replacement proof. Preserve CFG edges, phi results,
checks, tick counts and ordered selected-arm execution. This is a general validated
HIR transformation, independent of source spelling or benchmark identity.

Calls, intrinsics, sequence results and nested loops remain conservative. Unknown
callees can allocate or mutate their own storage; there is no interprocedural effect
summary proving otherwise. A scalar-only arm can qualify independently of its
allocating sibling. Replacement branches keep their existing transfer protocol.

## Alternatives

Eager select lowering would expose unselected traps/effects. Special branchless
syntax or SIMD operations would avoid rather than solve the compiler defect.
Removing captures from semantic liveness would change quota and alias semantics.
Whole-program call-effect analysis is separate future work, not assumed implicitly.

## Consequences

Scalar nested conditionals can retain loop state roots outside the backedge.
Nested calls, allocations and escaping sequence results can remain expensive;
measurement reports this boundary explicitly. Proof depth follows validated HIR
nesting limits. Conservative failures retain the original safe path. No syntax,
profile, quota, plugin ABI or language semantics change.

## Status

Accepted implementation experiment. Validation includes O0/O2 lazy trap/effect
ordering tests, IR root-traffic assertions, ASan/UBSan and three differential seeds.

[measurements](../../benchmarks/reports/2026-10-03/LAZY_REGIONS.md).
