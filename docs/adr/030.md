# ADR 030 — Acyclic dynamic record buffers and index links

## Context

ADR 028's products cannot form dynamic homogeneous node/interval collections;
plugins cannot define types. The frozen catalogue has 14 unsupported tasks, but
only BST is an unequivocal recursive-storage blocker: Camicia/Forth/Alphametics
also lack verified adapters. Do not equate providing storage with solving them.
Graphs/grid solutions and Go Counting illustrate the cost of flat encodings.
ADR 026 demands fundamental storage contracts rather than more algorithms.

## Decision

Add `v[Record]`, a homogeneous dynamic buffer of an earlier nominal record type,
and `!buffer[Record](length,fill)`. Existing length/index/replacement/concat/slice
contracts generalize. A record can contain existing sequences/maps or a buffer of
an earlier record. Wrapper records give typed nested collections (for example
Edge(to:i), Row(edges:v[Edge]), then v[Row]). Node children are checked integer
indices; -1 is an application sentinel, never an address. No recursive types,
cyclic values, reference types, ownership syntax or garbage collector.

Record buffers, including sequence-bearing records, are in scope. Existing
scalar-record map values remain supported unchanged. Sequence-bearing record map
values, direct sequence-valued generic maps and nested maps are deferred: existing
maps pack values as owned bytes, so inserting pointers would require a separate
managed keyed-layout/repack contract. Nested collections are delivered through
record buffers, including map fields, rather than claiming generic maps landed.

### Value, layout, lifetime and quota

Values are immutable. Index returns a record whose dynamic leaves alias the
original leaves. Functional replacement and growth preserve every old alias.
Native storage packs the validated record into 8-byte slots, including private
handles for dynamic leaves; bool/f64/u64/i64 use one, u128 uses two. A private
compile-time descriptor enumerates dynamic slots. Each record buffer has metadata
plus live-capacity payload, charged against the same 64 MiB quota. Specify the
exact header/metadata charge in the spec before shipping; spare capacity is charged.
No public layout/ABI or address exposure.

Outer live roots must retain every contained dynamic leaf transitively. A distinct
child-edge root contributes to child uniqueness; repeated handles remain aliases.
The acyclic type graph bounds traversal depth. This extends existing shadow roots,
not user-level reference counting or cycle tracing. A buffer's payload may be
updated only when static last-use and actual root uniqueness both hold. A child
extracted while its parent remains live must not become falsely unique. Transfer
gaps cannot collect children before their new roots are installed.

Reuse existing single-use replacement/append proof, with defensive runtime alias
checks. Scalar-record update loops should be linear; append geometric capacity
should be amortized linear. Dynamic-child installation/removal and transitive
root transitions can cost the number of child handles; report curves rather than
promise flat cost. Record-field append remains conservative unless separately
proved; this goal does not silently expand field-sensitive mutation proofs.

### Plugin capability compatibility

ADR 029 requires explicit support for a later core type rather than silently
assuming an old provider understands it. Add optional `types record-buffer` to
version 1 manifests. Without it, a provider whose imported registry or validated
signature/body contains the new type is rejected E024. Old-type providers remain
compatible. Unknown/duplicate capability declarations are rejected. Providers
still cannot add/redefine types; derived borrow proofs and the trusted-source,
non-binary interface remain unchanged. The shipped recipe is compiler-visible and
explicitly supports the expanded registry. This is a type-capability contract,
not a new intrinsic or authorization for native/allocating providers.

### Errors, order and ordering

Construction evaluates length then fill; negative length fails E013, reservation
then quota E013. Length/index/replacement evaluate receiver then index then value;
index E012 precedes quota. Type/placement/unknown record errors E023 or existing
arity E006/type E007 precede execution. Slice range E012 precedes quota; concat
capacity overflow/quota E013. Arguments evaluate once left-to-right; lazy arms
stay lazy. No new failure codes.

Each snapshots the outer collection and exposes typed record elements in index
order. Explicit updates do not change the snapshot. Record comparison/sort is
not invented: sorting a record buffer fails E018 for supported mode values (invalid
mode range E012 first), before quota. Existing scalar-buffer and map sorting is
unchanged; records can carry those sortable collections. Algorithmic record sorting
needs a later library comparator/key contract rather than arbitrary field ordering.

### Binding ADR 026 classifications and surface delta

| Addition/generalization | Verdict | Why |
|---|---|---|
| Record-buffer constructor | Core storage | Typed capacity, transitive ownership, quota |
| Length/index | Core storage | Typed borrowed leaves, checked index |
| Functional replacement | Core storage | Immutable aliases and last-use reuse |
| Concat/slice | Core storage | Capacity growth/owned copy and child roots |
| Each record elements | Existing core lowering | Snapshot lifetime and typed loop state |

Intrinsic variants remain **32 → 32**, executable core algorithms remain 31 plus
migrated equality adapter. Add a typed constructor HIR operation; reuse existing
storage operations, not new convenience names. Reject tree/BFS/merge algorithms,
default construction, record ordering and serialization as future libraries.

### Preregistered evidence

Four new externally derived tasks: linked-list traversal, BST insert/in-order,
graph traversal with typed adjacency rows and interval merge. Freeze task intent,
provenance and oracles before source-density results. Attempt frozen BST first;
report other unsupported adapters honestly. Original tasks/oracles/goldens and
baseline sources do not change. Separate original, external and combined density
cuts plus new-task cohort; no token savings forecast on untouched sources.
Measure build/update at increasing sizes, dynamic nested aliases and quota, and
25-repeat existing controls. Extend fuzz for children shared across containers,
callee/loop/lazy roots, plugins, snapshot iteration and allocation boundaries.

## Alternatives

True references/recursive types require cycle/share/lifetime semantics and cannot
use the current acyclic retention argument. Reference counting/GC changes the
memory model and is excluded. Flat scalar buffers already encode indices but lack
typed products/nested children; they do not solve the general-purpose representation
problem. Fully generic Type trees would remove today's Copy type IDs and expand
all collection/keyed ownership contracts at once. Nominal wrapper products preserve
bounded registry/type identity and make the smallest useful first step.

## Consequences

Typed node buffers express index-linked trees/lists/heaps/intervals; nested rows
express adjacency without cycles in the type graph. Integer links remain ordinary
checked indices, not automatically validated graph edges. Some nested/map shapes
remain deferred explicitly. Stop if child lifetime, quota or uniqueness cannot be
proved; do not weaken proofs to make benchmarks pass.

## Status

Preregistered before implementation. No unsupported-count/density claim yet.
