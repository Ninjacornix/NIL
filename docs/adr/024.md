# ADR 024 — Retain v5 syntax after token attribution

## Context

The 32 supported external pairs cost 5686 NIL versus 5036 Python cl100k tokens
(+650, +12.91%). Previous capability additions did not close the gap. Repeated
signature declarations and unchanged loop operands were plausible surface causes;
local textual repetition already has an overseer-estimated combined ceiling of 3.3%.
The [preregistered attribution and remediation plan](../../benchmarks/reports/2026-10-03/V5_ATTRIBUTION_PLAN.md)
classifies every token under four pinned real vocabularies with exact accounting.

## Decision

Make no compiler or surface change in this round. Numeric literals are the largest
fractional cl100k surplus (+394), followed by operators (+325.738), separators
(+320.513), and signatures (+318). These positive costs coexist with substantial
NIL savings in whitespace, keywords and identifiers; all categories sum to +650.
They describe current programs, not a proof of a minimal language representation.

Whole-source counterfactual signature references save only 32 cl100k tokens across
all external tasks (78 Gemma); deleting bare unchanged loop operands saves 9 (131
Gemma). Neither removes the dominant algorithm expansion. Most constants already
cost one token. Intrinsic names favour NIL; renaming is not justified. Do not add
syntax, bindings or name compression on these forecasts.

Grade school, Connect and ETL contribute +523 of the net 650 tokens. Their sources
expose sorting/comparison, coordinate traversal, and format parsing/serialization
costs. Recommend a separate semantic-abstraction design decision with executable
reference rewrites before predicting savings. This is not evidence that immutable
values or explicit loop state must be abandoned, nor a claim that a new operation
will necessarily pay for itself. There is no justified numerical prediction for
that larger design yet.

## Alternatives

- Signature reference spelling `^a=`: small saving, adds source-level declaration
  dependencies; unimplemented and invalid in the current grammar.
- Empty step operands: tiny BPE saving despite removing 77 state identifiers; new
  grammar and repair obligations have not been justified.
- Local bindings: textual repeats are not necessarily shareable across scopes,
  lazy arms or effects. The existing ceiling cannot close the measured gap.
- Redesign evaluation or add comparison/sorting/field abstractions: separate work,
  no causal savings estimate or settled design in this ADR.

## Consequences

No existing program's meaning changes. All profiles, default, quota and map ceiling
stay unchanged. All corpus sources, tasks, oracles, goldens and baselines remain
unchanged. Reverification and performance controls are required despite shipping
analysis only. Forecast-versus-implemented saving is not applicable; actual
implemented savings are zero. Raw density still does not establish total model
tokens to correctness; the unfavourable generation study remains the relevant
model evidence.

## Status

Accepted: retain current surface this round. Larger semantic-remediation proposals
remain unresolved; this ADR does not approve their implementation.
