# ADR-001: Rust implementation

## Context

The user requires Rust; report.md recommends Rust structs/enums and a handwritten frontend.

## Decision

Use a Rust workspace, edition 2024, minimum declared Rust 1.85. Keep the scaffold and planned M1 dependency-free. Start with one CLI crate; add nil-hir and nil-compiler when implementing real boundaries.

## Alternatives

C++ for direct LLVM integration; Python for prototyping; separate crates for every module.

## Consequences

Rust provides explicit enums and checks without requiring a large framework. Python remains an option for future tokenizer/model tooling. No nightly features are required.

## Status

Accepted.
